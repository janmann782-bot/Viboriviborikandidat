КАНАЛ С ЖИВОЙ КАРТОЙ

Бота можно добавить в Telegram-канал.

Как подключить:
1. Добавь бота в канал со своего Telegram-аккаунта 7787565361.
2. Назначь бота администратором.
3. Дай права на публикацию и редактирование сообщений.
4. Бот автоматически запомнит этот канал.
5. В канал будет опубликована одна карта выборов.

Важно:
- бот публикует в канал ТОЛЬКО карту;
- без текстовых результатов;
- без уведомлений;
- без админских сообщений;
- без кнопок под постом;
- новые посты при каждом обновлении не создаются;
- бот редактирует один и тот же пост с картой.

Если карта в регионе меняет лидера, цвет региона на карте изменится.

Частота:
- тест 1 минута - примерно раз в 5 секунд;
- обычные выборы - примерно раз в 30 секунд.

В /admin есть кнопка "📢 Канал".
Там можно:
- проверить подключение;
- вручную обновить карту;
- отключить канал и удалить пост с картой.

Если бот уже был администратором канала до установки v4:
- убери его из администраторов и назначь снова;
или
- удали из канала и добавь заново.
Это нужно, чтобы Telegram прислал событие подключения.

ЗАПУСК

1. Переименуй .env.example в .env
2. Вставь:
   BOT_TOKEN=твой_токен
3. Установи:
   py -m pip install -r requirements.txt
4. Запусти:
   py bot.py
