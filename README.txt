РОФЛ-ВЫБОРЫ - TELEGRAM БОТ

Что лежит в архиве
- bot.py - весь бот в одном файле
- requirements.txt - зависимость aiogram
- README.txt - эта инструкция

Никаких папок проекту не нужно.
SQLite-база elections.db создастся автоматически рядом с bot.py после первого запуска.

1. Создай бота через @BotFather
2. Получи токен
3. Установи Python 3.11+ желательно
4. В папке с файлами выполни:

Windows:
    py -m pip install -r requirements.txt

Linux/macOS:
    python3 -m pip install -r requirements.txt

5. Задай токен

Windows PowerShell:
    $env:BOT_TOKEN="ТВОЙ_ТОКЕН"

Windows cmd:
    set BOT_TOKEN=ТВОЙ_ТОКЕН

Linux/macOS:
    export BOT_TOKEN="ТВОЙ_ТОКЕН"

6. Запусти

Windows:
    py bot.py

Linux/macOS:
    python3 bot.py


АДМИН

Админ жестко задан в bot.py:
    ADMIN_ID = 7787565361

Другие пользователи открыть админку не смогут.

Основные возможности:
- тест на 1 минуту
- обычные выборы на 3 дня
- живое табло, которое само редактируется
- пауза и продолжение
- ручное создание нового живого табло
- завершение с мгновенным досчетом остатка
- полный сброс
- рандомизация скрытой итоговой явки по регионам
- изменение населения региона
- изменение итоговой явки региона
- админ-статистика с реальными голосами
- экспорт результатов в CSV


КОМАНДЫ

Для всех:
    /start
    /results

Только для админа:
    /admin
    /adminstatus
    /regions
    /setpop НОМЕР НАСЕЛЕНИЕ
    /setturnout НОМЕР ПРОЦЕНТ

Примеры:
    /setpop 3 15000
    /setturnout 3 64.5


КАК СЧИТАЮТСЯ ГОЛОСА

Реальный человек голосует один раз:
    регион -> партия -> подтверждение

Его Telegram ID используется только для защиты от повторного голосования.

У каждого региона есть:
- население
- скрытая итоговая явка
- реальные голоса игроков
- виртуальные бюллетени

Если реальные голоса в регионе сейчас такие:
    Новый 57 - 6
    Единый 57 - 2
    Бебрики - 3

то следующие виртуальные пачки чаще идут за "Новый 57", но не идеально в тех же процентах.
Есть небольшой случайный шум.

Уже посчитанные виртуальные голоса никогда не переписываются назад.
Если позже приходят новые реальные люди и расклад меняется, меняется только распределение следующих пачек.

Если в регионе пока никто из реальных людей не голосовал, стартовая вероятность у трех партий одинаковая.

Явка никогда автоматически не ставится 100%.
По умолчанию у каждого региона она случайная от 52% до 72%.
Админ может изменить ее вручную.


ТЕСТ 1 МИНУТА

В тесте вся трехдневная динамика сжимается в 60 секунд.
Это специально сделано, чтобы быстро проверить:
- как растет явка
- как меняются проценты
- как приход новых реальных голосов влияет на следующие пачки
- как обновляется живое сообщение

При запуске теста старые голоса очищаются.

ПЕРЕЗАПУСК

Все состояние хранится в elections.db.
Если бот перезапустить во время выборов, голоса не пропадут.
Симуляция продолжит работать после запуска процесса.
